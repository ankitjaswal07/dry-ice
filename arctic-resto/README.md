# ArcticRestoDRY ICE — WordPress + Elementor Theme (v2.0.0)

**Brand:** ArcticRestoDRY ICE  
**Tagline:** *Quality Dry Ice. Reliable Supply. Flexible Solutions.*

Industrial B2B and commercial WordPress + Elementor theme built for dry ice manufacturing, product supply (pellets, nuggets, blocks), bulk and recurring delivery programs, cold-chain applications, safety education, and quote conversion.

---

## Quick Start & Installation

1. Upload and activate `arctic-resto-dry-ice.zip` (or `arctic-resto-latest.zip`) in **WordPress Admin → Appearance → Themes**.
2. Install and activate the free **Elementor** plugin (**Plugins → Add New → Elementor**). *(Elementor Pro is completely optional.)*
3. Go to **Appearance → Dry Ice Demo Import** and click **Import / Refresh ArcticRestoDRY ICE Website Content** to provision all 16 Elementor-built pages, 4 Dry Ice Product CPT entries, 8 Industries Served entries, 3 editable Delivery Zone placeholders, 8 full-length technical blog articles, media assets, and navigation menus.
4. Go to **Appearance → Customize → ArcticRestoDRY ICE Settings** to enter your verified business phone, email, facility address, operating hours, quote notification email, and customize the secondary cross-promotion callout for **Arctic Resto Dry Ice Cleaning Services (`https://arcticresto.com/`)**.
